# packages.txt — the packages install.sh puts on every machine.
#
#   <name>  [via=auto|vendor|native]  [cmd=<command>]  [<pm>=<package>|-] ...
#
#   via=auto    (default) search the system package manager; if it isn't there,
#               fall back to an upstream installer (vendor_<name> in install.sh)
#   via=vendor  always use the official upstream release, installed into ~/.local
#               (current version, no sudo). Falls back to the package manager
#               where upstream has no build (eza on macOS, glibc-only builds on Alpine)
#   via=native  system package manager only
#   cmd=        command that shows it's already installed (default <name>; '-' = custom check)
#   only=       install only on these platforms: linux, darwin, wsl (comma-separated)
#   <pm>=       package name when it differs for apt, dnf, pacman, zypper, apk or port
#               (MacPorts, used only if installed); '-' means "not available there"
#
# Adding something from your distro's repos is just a new line with its name, e.g.
#   jq
#   htop
#
# Why the cloud/k8s tools and editors are via=vendor: distro repos lag badly
# (Ubuntu 22.04 ships neovim 0.6, Go 1.18 and AWS CLI v1) and macOS has no
# package manager here at all.
